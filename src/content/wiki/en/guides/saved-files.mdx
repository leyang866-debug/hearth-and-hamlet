## Windows save location

SteamDB's User File System listing identifies this Godot app-data folder for the Windows installation:

```text
%APPDATA%\Godot\app_userdata\Hearth and Hamlet
```

Save files use the `.save` extension. Paste `%APPDATA%` into File Explorer or the Win + R dialog instead of publishing your personal Windows username.

## Safe backup process

1. Exit the game and wait for Steam Cloud activity to finish.
2. Search your user-data folders and Steam userdata for recently modified game-related folders.
3. Copy a candidate save folder to a separate backup location before editing, deleting, or replacing files.
4. Record the original path and restore the backup if the game fails to load it.

## Troubleshooting boundaries

Steam Cloud may synchronize files after launch, so a local change can be overwritten. Avoid deleting unknown files and use official support or community documentation when an exact path is confirmed.

## FAQ

### Where are Hearth and Hamlet saves stored?

The listed Windows location is `%APPDATA%\Godot\app_userdata\Hearth and Hamlet`. Confirm the folder exists on your installation before changing anything.

### Should I edit my save file?

Only after making a complete backup and confirming the file is actually used by the game.

### Can Steam Cloud overwrite a local backup?

Cloud synchronization can replace local data. Keep a separate copy outside the active save directory.
